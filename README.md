# Tracker Tontonan

Aplikasi untuk mencatat film, series, dan anime yang ingin, sedang, atau sudah ditonton.
Dibuat dengan React + Vite + Tailwind CSS.

## Struktur Komponen
- `Header.jsx`: navigasi
- `Footer.jsx`: footer
- `Beranda.jsx`: halaman beranda
- `Body.jsx`: halaman daftar tontonan
- `Card.jsx`: kartu tontonan (dipakai berulang)

## Cara Menjalankan
npm install
npm run dev

## Cabang
- `main`: versi React
- `versi-html`: versi HTML + Tailwind sebelumnya
